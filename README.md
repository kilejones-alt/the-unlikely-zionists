# The Unlikely Zionists

Public source repository for the developing interactive storytelling website. The source includes a WebGL2 frontend and a **development-only** private-submission/moderation backend.

**Important:** Publishing this source does not activate private submissions. Do not accept actual participant stories or photographs until a secure server, credentials, storage, privacy notice, consent workflow, and security review are configured. GitHub Pages is static hosting and cannot run the private backend.

The site uses five empty story placeholders; no fictional participant stories or photographs are published.

This repository is a work in progress. All editorial copy and public program materials are drafts pending approval.
